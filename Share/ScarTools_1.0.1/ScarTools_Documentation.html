Overview • Setup

ScarTools 1.0.1 Production Manual

Unified department suite for Autodesk Maya (2023, 2024, 2025, 2026+) on Windows 10/11 x64.
✓ Supported Host Platforms: Autodesk Maya 2023, 2024, 2025, 2026+ on Windows 10/11 (AMD64).

1-Drag Viewport Installation

ScarTools installs in under 3 seconds using the native Maya viewport drag-and-drop installer:

  1. Navigate to the network folder O:\Rnd\Scripts\ScarPipline\Share\ScarTools_1.0.1 (or extract the zip).
  2. Drag drag_drop_install.py directly from Windows Explorer into any open Maya 3D viewport.
  3. Click INSTALL in the setup dialog.
  4. The top menu ScarTools and the dedicated ScarTools shelf tab are registered immediately without restarting Maya!

Studio Architecture Principles

  • Centralized Design System (scartools.ui): Unified UI tokens, modern palettes, high-DPI custom icons, and rollup titlebars across all windows.
  • Global Log Viewer: Centralized event bus capturing real-time diagnostic output, warnings, errors, and successes across all tools.
  • Atomic Scene Transactions: Multi-step actions are wrapped in SceneTransaction for instantaneous 1-click single Undo.
  • Smart Cross-Department Transfers: Material and skin snapshots intelligently transfer across departments (e.g. Model scene to Rig scene to Animation scene).
Department Tools • Animation

Anim Export

Automated shot animation cache extraction into studio pipeline directories (Alembic/ and FBX/).
💡 Dedicated Animation Cache Export

Eliminates manual file browsing and human error when exporting animated shots. Automatically bakes world-space cameras, extracts deforming character and prop geometry caches with vertex velocity vectors, and organizes output directly into studio Alembic/ and FBX/ folders alongside Maya/ scene files.

Standardized Studio Directory Structure

Shot_010/ ├── Maya/ # Maya working scene files (e.g. PRT_SH_010_ANM_V001.ma) ├── Alembic/ # Alembic point & geometry caches (.abc) with velocity vectors └── FBX/ # FBX character, prop, and camera animation takes (.fbx)

Core Supported Formats

Category Destination Folder Key Capabilities & Features
Shot Camera FBX/ or Alembic/ Bakes world-space constraints, focal length animation, filmback/aperture, clip planes, and camera shake curves.
Characters & Creatures Alembic/ & FBX/ Bakes vertex deformation, normals, UVs, and motion blur velocity vectors (-writeVelocities) for Arnold, V-Ray, and Houdini FX.
Props & Environment Alembic/ & FBX/ Extracts hierarchical transforms and mesh geometry caches for set dressing and interactable props.
Shot Package Manifest shot_manifest.json Auto-generates shot_manifest.json capturing exact frame ranges, simulation handles, FPS, active camera, and relative asset paths.

1-Click Export Workflow

  1. Open Anim Export from the ScarTools shelf or menu.
  2. The tool automatically inspects the active Maya scene (e.g. PRT_SH_010_ANM_V001.ma) and auto-populates the Shot Name (PRT_SH_010) and Shot Root Path.
  3. Select your Frame Range (Timeline or Custom) and set Simulation Handles (e.g. ±5 frames for FX).
  4. Select the active Shot Camera and choose format (FBX (.fbx) or Alembic (.abc)).
  5. Check the characters and props in the data table, then click EXPORT SHOT CACHES. All caches are automatically saved into Alembic/ and FBX/ subfolders.

Model & Scene Sanitizer

Comprehensive 26-rule preflight QA inspector and atomic 1-click geometry repair tool.

All 26 Preflight QA Rules

Category Rule Severity Safe Auto-Fix Action
Topology N-Gons (>4 sides) ERROR Viewport component selection for manual quad-tessellation.
Topology Triangles WARN Viewport component selection for edge-flow review.
Topology Non-Manifold Geometry ERROR Automated non-manifold vertex/edge split & cleanup.
Topology Lamina Faces (stacked faces) ERROR Automated removal of duplicate coincident faces.
Topology Zero-Area Faces / Zero-Length Edges WARN Automated vertex collapse within 0.0001 tolerance.
Transforms Unfrozen Transforms ERROR Freezes Translate (0,0,0), Rotate (0,0,0), and Scale (1,1,1).
Transforms Off-Center Pivots WARN Centers pivot to bounding box center.
Transforms Negative Scales ERROR Inverts negative scale and flips face normals.
Naming Duplicate Node Names ERROR Sequentially renames duplicates (e.g. mesh_01, mesh_02).
Naming Default Names (pCube1) WARN Highlights generic objects requiring asset naming conventions.
Display & Layers Unused Shading Nodes / History INFO Deletes unattached shading nodes and non-deformer history.

User Actions & Buttons

  • 🔍 Inspect Geometry: Scans the scene/selection and populates the issues table with severity chips.
  • 🎯 Select Issue Components: Automatically selects the exact offending vertices, edges, or faces in the Maya 3D viewport.
  • ⚡ Fix All Safe Issues: Atomically executes safe fixes (freezes transforms, cleans lamina faces, deletes non-deformer history) in a single undo step.
Department Tools • Rigging

Skin Tools (Character Weighting Suite)

Symmetry-aware mirroring, multi-mesh skin weight transfers, pruning, and snapshot archives.

Tab Breakdown & Operations

1. Mirror Skin Weights

Mirrors weights across positive and negative axes with automatic component selection detection and label replacement (L_ ↔ R_).

  • Mirror Planes: $X \to -X$, $-X \to +X$, $Y \to -Y$, $Z \to -Z$.
  • Surface Association: Closest Point on Surface, Ray Cast, Closest Component.
  • Influence Association: One to One, Closest Joint, Label Match.
2. Copy Skin Weights & Clusters

Transfers skin clusters from a single source mesh onto one or dozens of target meshes simultaneously.

  • Copy Mode: Copy SkinCluster (creates and binds new skin clusters if unskinned) or Weights Only.
  • Interpolation: Closest Point, UV Space, or Component ID.
3. Skin Weights Cleanup
  • Prune Small Weights: Removes weights below a specified threshold (e.g. 0.001).
  • Clamp Max Influences: Restricts vertices to a maximum joint count (e.g. 4 for Unity/Unreal, 8 for Film).
  • Remove Unused Influences: Unbinds joints with zero weight influence to keep rig evaluations lightning fast.
  • Unbind Skin: Safely unbinds selected meshes with optional history retention.
4. Export & Import Skin Snapshots

Packages all selected meshes into a single packed skin_weights_package.json file with automated versioning (v001, v002, v003).

Department Tools • Texturing

Generate UDIM (1-Click Previews)

Zero-window 1-click hardware UV tile mipmap preview generator and Viewport 2.0 cache refresher.
⚡ Fast 1-Click Workflow: Clicking Generate UDIM in the ScarTools menu or shelf immediately processes the scene without opening any modal dialogs.

What Happens in the Background:

  1. Auto-Format UDIM Tokens: Automatically converts numbered texture filenames (e.g. BaseColor.1001.png → BaseColor.<UDIM>.png) and sets UV Tiling Mode to UDIM (Mari).
  2. C++ Hardware Preview Generation: Executes native Maya generateUvTilePreview on all connected file nodes.
  3. Viewport 2.0 Flush: Flushes GPU texture memory and forces Viewport 2.0 to reload high-resolution mipmaps.
  4. Textured Display Activation: Switches the active Maya 3D viewport to Textured Mode (Key 6) so materials show up instantly.
  5. In-View HUD Banner: Displays an unobtrusive green confirmation message with the total number of texture nodes processed.

Framework (Transactions & Logging)

Package: scartools.framework

Atomic Scene Transactions

Wrap any complex multi-command pipeline script in SceneTransaction for safe, 1-click Undo:

from scartools.framework.transactions import SceneTransaction
import maya.cmds as cmds

with SceneTransaction("Batch Prop Placement"):
    for i in range(10):
        loc = cmds.spaceLocator(name=f"marker_{i:02d}_LOC")[0]
        cmds.move(i * 2, 0, 0, loc)
# Single Ctrl+Z in Maya completely undos all 10 locators atomically!

Centralized Event Logging

from scartools.framework.logging import emit_log

# Emit diagnostics directly to the global Log Viewer
emit_log("Rigging", "Bound 42 joints successfully", level="SUCCESS")
emit_log("Shading", "Missing UDIM tile 1008 on BaseColor", level="WARN")
emit_log("Sanitizer", "Non-manifold vertex detected on mesh_01", level="ERROR")
